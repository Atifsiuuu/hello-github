# Hello GitHub

A small Python starter project: a command-line program that prints a greeting.
It uses only Python's standard library, so there are no packages to install.

## Requirements

- Python 3.10 or newer

## Run it

From this repository's folder, run:

```sh
python hello.py
```

Output:

```text
Hello, World!
```

Choose a name:

```sh
python hello.py --name "GitHub"
```

Output:

```text
Hello, GitHub!
```

See the available options:

```sh
python hello.py --help
```
